# Access Service

The Access Service is responsible for managing access rights and user groups in the Gaeco ecosystem. It provides an API for creating, updating, and deleting access rights, as well as managing user group memberships.

## Docker Setup

The main Docker files in this folder describe the containerized AccessService stack.

For local development with the AccessService server and client running from your IDE, use the focused dependency stack documented in [dev/README.md](dev/README.md).
